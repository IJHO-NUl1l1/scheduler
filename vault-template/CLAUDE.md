# 플래너 볼트 규칙

이 폴더는 일정·할 일 데이터다. 수정할 때 아래 형식을 반드시 지킨다.

## 파일

- `Daily/YYYY-MM-DD.md`: 그날 일정과 할 일. frontmatter에 `date`, 선택으로 `headline`(월 달력에 보이는 한 줄).
- `Monthly/YYYY-MM.md`: `## 목표`, `## 메모`
- `Yearly/YYYY.md`: `## 목표`
- 월·연 목표도 할 일처럼 `- [ ] 내용 🆔 id` 체크박스로 쓴다 (달성률 계산용).
- `Inbox.md`: 날짜 없는 할 일
- `.planner/`: 앱 전용. 건드리지 않는다. (계획 제안은 `.planner/proposals/`에만 새 파일로 작성 가능)

## Daily 섹션

그날 항목은 전부 `## 할 일` 한 목록에 쓴다. 시간은 선택이고 체크박스 바로 뒤에 쓴다.

```
## 할 일
- 종일 연차
- [ ] 10:00-11:00 시간 정해진 할 일 🆔 a7k2m9
- 14:00-15:00 회의 (체크박스 없음 = 일정) 🆔 c4n8q1
- [ ] 시간 없는 할 일 📅 2026-11-28 ⏫ 🆔 k3f9a2
  - [ ] 16:00-17:00 하위 항목도 시간 가능 🆔 k3f9b0

## 메모
```

## 할 일 기호

우선순위 🔺⏫🔼🔽⏬, 마감 📅, 예정 ⏳, 시작 🛫, 완료 ✅, ID 🆔(소문자 영숫자 6자). 날짜는 `YYYY-MM-DD`.

## 수정 원칙

1. 필요한 줄만 고친다. 다른 내용은 그대로 둔다.
2. 새 할 일에는 겹치지 않는 🆔를 붙인다. 기존 🆔는 바꾸지 않는다.
3. 완료 처리는 `[ ]` → `[x]`, 끝에 `✅ 오늘날짜`.
4. 큰 재계획은 바로 고치지 말고 먼저 변경안을 보여주고 확인받는다.
