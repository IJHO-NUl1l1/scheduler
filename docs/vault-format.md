# 볼트 파일 형식 명세

`packages/core`의 파서와 쓰기 로직은 이 문서를 기준으로 구현한다. 할 일 문법은 Obsidian Tasks 플러그인과 호환된다.

## 폴더

| 경로 | 내용 |
|---|---|
| `Yearly/YYYY.md` | 연간 목표 |
| `Monthly/YYYY-MM.md` | 월 목표, 메모 |
| `Daily/YYYY-MM-DD.md` | 그날 headline, 일정, 할 일, 메모 |
| `Inbox.md` | 날짜 없는 할 일 |
| `CLAUDE.md` | AI용 규칙서 |
| `.planner/layout.json` | 위젯 배치 (앱 전용) |
| `.planner/proposals/*.md` | AI가 제안한 계획 (승인 대기) |

파일은 필요할 때 만든다. 없는 날짜의 Daily 파일은 "비어 있음"으로 취급한다.

## Daily

```markdown
---
date: 2026-11-24
headline: 복지관 공모사업 게시판 시안
---
## 할 일
- 종일 연차
- [ ] 10:00-11:00 프린터 점검 🆔 a7k2m9
- 14:00-15:00 회의 🆔 c4n8q1
- [ ] 학업계획서 초안 📅 2026-11-28 ⏫ 🆔 k3f9a2
  - [ ] 16:00-17:00 자료 조사 🆔 k3f9b0
  - [ ] 목차 잡기 🆔 k3f9b1
- [x] 네트워크 장애 보고 🆔 p01c7d ✅ 2026-11-24

## 메모
자유 형식
```

- `headline`: 선택. 월간 달력에 표시되는 한 줄.
- 섹션 제목(`## 할 일`, `## 메모`)은 고정. 그 밖의 섹션은 파서가 무시하고 그대로 보존한다.

### 하나의 목록, 시간은 선택

그날의 모든 항목은 `## 할 일` 한 목록에 둔다. 시간이 정해진 항목과 안 정해진 항목을 섹션으로 나누지 않는다. 타임라인은 이 목록에서 시간이 있는 항목만 뽑아서 그린다.

| 줄 형태 | 종류 | 완료 체크 |
|---|---|---|
| `- [ ] 내용` | 할 일 (시간 없음) | O |
| `- [ ] HH:mm 내용` / `- [ ] HH:mm-HH:mm 내용` | 시간 정해진 할 일 | O |
| `- HH:mm-HH:mm 내용` (체크박스 없음) | 일정 (회의 등) | X, 시간이 지나면 끝난 것으로 취급 |
| `- 종일 내용` | 종일 일정 | X |

- 시간은 체크박스 바로 뒤, 24시간제. `10:00-11:00`과 `10:00 - 11:00` 둘 다 읽고, 쓸 때는 `10:00-11:00`.
- 시작만 있으면 표시용 기본 길이(30분)를 쓴다. 파일에는 적지 않는다.
- 하위 항목도 자기 시간을 가질 수 있다. 부모는 시간이 없어도 된다.
- 예전 형식의 `## 일정` 섹션도 읽는다. 그 안의 줄은 체크박스 없는 일정으로 취급하고, 새로 쓸 때는 `## 할 일`에 쓴다.

## 할 일 줄

```
- [ ] 내용 [⏫] [📅 YYYY-MM-DD] [⏳ YYYY-MM-DD] [🔁 규칙] [🆔 id] [✅ YYYY-MM-DD]
```

| 기호 | 의미 |
|---|---|
| `[ ]` / `[x]` | 미완료 / 완료 |
| 🔺 ⏫ 🔼 🔽 ⏬ | 우선순위: 최상 / 높음 / 중간 / 낮음 / 최하 |
| 📅 | 마감일 |
| ⏳ | 예정일 (하기로 한 날) |
| 🛫 | 시작일 |
| ➕ | 생성일 |
| ✅ | 완료일 |
| 🔁 | 반복 (MVP에서는 보존만 하고 처리하지 않음) |
| 🆔 | 고정 ID, 소문자 영숫자 6자 |

- ID가 없는 할 일(직접 적은 것)은 앱이나 MCP가 처음 수정할 때 ID를 붙인다.
- 들여쓴 하위 할 일은 부모에 속한 것으로 읽는다.

## Monthly

```markdown
---
month: 2026-11
---
## 목표
- [ ] 학업계획서 제출 🆔 m7x2k1
- [x] 게시판 시안 확정 🆔 m9q4z8 ✅ 2026-11-20

## 메모
```

월간 달력의 날짜 칸은 Monthly 파일이 아니라 각 Daily 파일의 `headline`에서 가져온다.

## Yearly

```markdown
---
year: 2026
---
## 목표
- [ ] 연간 목표 🆔 y3c8d0
```

월·연 목표는 할 일과 같은 문법(체크박스 + 기호)을 쓴다. 홈 화면에서 달성률을 계산하기 위해서다. 체크박스 없는 `- 목표`도 읽되, 달성률 계산에서는 빠진다.

## Inbox

```markdown
## 할 일
- [ ] 날짜 없는 할 일 🆔 a1b2c3
```

## 쓰기 규칙

1. 바뀐 줄만 고친다. 파일 전체를 다시 생성하지 않는다.
2. 모르는 섹션, 모르는 기호, 주석은 그대로 둔다.
3. 쓰기 직전에 파일을 다시 읽고, 임시 파일 → rename 으로 저장한다.
4. 줄바꿈은 LF, 인코딩은 UTF-8(BOM 없음).
