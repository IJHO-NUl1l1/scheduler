# 화면 구조

홈은 **대시보드(요약)** 로 바꾸고, 편집과 상세 정보는 탭으로 나눈다.
기준: 대시보드는 "지금 상태를 3초 안에 파악"만 한다. 목록 전체, 편집, 달력은 각 탭으로.

## 1. 요소 분류

| 요소 | 대시보드 | 있는 곳 | 비고 |
|---|---|---|---|
| 지금 / 다음 | **O** | 대시보드 맨 위 | 진행 중 항목, 남은 분, 다음 항목까지 남은 분 |
| 오늘 진행 (완료 n/m) | **O** | 오늘 탭 | 숫자 + 막대 |
| 오늘 남은 시간 일정 (다음 3개) | **O** | 대시보드 | 전체는 오늘 탭 |
| 주의 (밀린 n, 3일 내 마감 n) | **O** (개수만) | 대시보드 → 오늘 탭 | 0이면 숨김 |
| 이번 주 7일 띠 | **O** | 대시보드 → 캘린더 주 | 날짜, 헤드라인, 할 일 수 |
| 목표 달성률 (월·연) | **O** (막대만) | 대시보드 → 목표 탭 | |
| 인박스 개수 | **O** (숫자만) | 대시보드 → 인박스 탭 | |
| 일·월·연 진행률 | 작게 | 사이드바 | |
| 오늘 전체 목록 | X | 오늘 탭 | 편집 가능 |
| 타임라인 | X | 오늘 탭 | 드래그로 시간 이동·길이 조절, 목록에서 끌어다 놓기 |
| 밀린 할 일 목록 | X | 오늘 탭 (오늘 볼 때만) | 오늘로/내일로/삭제 |
| 헤드라인 편집 | X | 오늘 탭 상단 | 대시보드에는 표시만 |
| 메모 | X | 오늘 탭 하단 | 읽기 |
| 월 달력 | X | 캘린더 탭 › 월 | 날짜 간 드래그 이동, 날짜 클릭 → 오늘 탭 |
| 주간 보기 | X | 캘린더 탭 › 주 | 7열, 열 사이 드래그 |
| 다가오는 마감 목록 | X | 캘린더 탭 (오른쪽) | |
| 월 목표 목록 | X | 목표 탭 › 월 | 추가·수정·체크·삭제 |
| 연 목표 목록 | X | 목표 탭 › 연 | |
| 연간 기록 (12개월, 히트맵) | X | 목표 탭 › 연간 기록 | |
| 인박스 목록 | X | 인박스 탭 | |
| 빠른 추가 | 전역 | 모든 탭 상단 | 탭에 따라 기본 날짜가 바뀜 (오늘 탭은 보고 있는 날짜, 인박스 탭은 날짜 없음) |
| 항목 편집 | 전역 | 항목 클릭 → 오른쪽 편집 패널 | 내용, 종류, 날짜, 시간, 마감, 우선순위, 하위 항목, 삭제 |
| 되돌리기 | 전역 | 하단 알림 | 모든 수정 (추가, 삭제, 이동, 편집, 완료) |
| Claude 채팅 | 전역 | 오른쪽 패널 (사이드바에서 켜고 끔) | |
| 볼트 변경 | 전역 | 사이드바 하단 | |

## 2. 탭 구조

```
사이드바                    본문
──────────                 ──────────────────────────────────
Scheduler                  [탭 제목 · 날짜 이동]      [빠른 추가]
11월 25일 수 11:30          ──────────────────────────────────
오늘 ▓▓▓░ 48%               탭 내용
이번 달 ▓▓▓▓░
올해 ▓▓▓▓▓░

▣ 대시보드
☀ 오늘          5
▦ 캘린더          ← 내부 탭: 월 | 주
◎ 목표            ← 내부 탭: 월 목표 | 연 목표 | 연간 기록
▤ 인박스        3

──────────
◐ Claude (켜기/끄기)
볼트 이름
```

## 3. 탭별 구성

### 창 크기와 자동 확대
- 기준 1440×900 = 100%. 창이 커지면 가로·세로 중 덜 늘어난 쪽 비율로 화면 전체를 확대한다 (글씨·칸·아이콘·트리·장식 모두 같은 비율). 기준보다 작으면 줄이지 않고, 최대 200%
- main 프로세스의 `setZoomFactor`로 처리하므로 화면 코드는 1440×900 기준으로만 만들면 된다

### 머리줄 (모든 탭 공통)
- 모든 탭은 맨 위에 머리줄이 있고 스크롤되지 않는다. 배경·본문은 머리줄 아래부터 시작한다 (`PageHeader` + `PageBody`)
- 늘 들어가는 것: 오늘 날짜(회색 한 줄, 공휴일 포함) · 빠른 추가(오늘 탭은 그 날짜, 인박스는 날짜 없이) · 테마 장식(크리스마스: 금색 별·트리·전구, 별은 반짝임)
- 탭마다 다른 것: 제목(대시보드는 인사·남은 날·오늘 한 줄, 다른 탭은 날짜 넘기기 등)과 오른쪽 전환 버튼
- 대시보드의 "화면 편집" 버튼은 머리줄이 아니라 본문 위 오른쪽에 둔다

### 대시보드 = 12열 격자 위의 위젯 (사용자가 구성)
- 구성은 볼트의 `.planner/layout.json`(version 3: 위젯마다 x, y, w, h)에 저장 → 집·회사에서 같은 화면. 예전 v2(섹션) 파일은 자동 변환
- 행 높이 40px, 간격 14px. 편집 모드에서 격자 칸이 보인다
- 끌기: 위젯이 떠올라(반투명·기울기·그림자) 커서를 따라오고, 놓일 자리는 점선으로 보인다. 다른 위젯은 미리 비켜난다
- 다른 위젯 위에 놓으면 맞바꾸기 (크기 유지). 같은 줄이면 줄 안에서 순서만 바꿔 빈칸 없이 다시 채움
- 빈 곳에 놓으면 그 칸으로, 위에 빈칸이 있으면 끌어올림(중력). 겹치면 아래로 밀림
- 오른쪽 아래 모서리를 끌어 칸 단위로 크기 조절 (위젯마다 최소 크기)
- 구역 나누기는 "제목" 위젯 (여러 개 가능, 이름 편집)
- 위젯 (겹치지 않게 역할을 나눈다):
  - **다음 할 일**: 다음에 할 일 하나만 크게. 시간이 정해진 다음 일정·할 일, 없으면 시간 없는 할 일 맨 위 (바로 체크). 기본 구성에서는 '오늘 할 일' 바로 아래
  - **챙길 것**: 밀린 할 일(지난 날짜·시간 지난 미완료)과 7일 안 마감을 실제 항목으로. 바로 "오늘로" 옮기기
  - **오늘 할 일** / **오늘 타임라인**: 오늘 목록(남은 것 위, 완료한 것은 아래에 줄 그어서)과 시간표
  - **앞으로 7일**, **월 달력**: 날짜 흐름
  - **목표**: 이번 달·올해 목표 달성률 (마감 개수는 '챙길 것'으로)
  - **인박스**: 날짜 없는 할 일
  - **기록**: GitHub 잔디와 같은 모양. 칸 진하기는 그날 할 일 완료율(0 / ~33% / ~66% / 100% 미만 / 100%). 위에 월, 왼쪽에 월·수·금, 위에 '완료 수 · 모두 끝낸 날 수', 아래에 연속 일수(칸에 올리면 그날 완료/전체와 %)와 0%–100% 범례. 색은 테마 `--heat-0..4` (기본: GitHub 초록, 크리스마스: 짙은 초록→초록→빨강, 100%인 날은 은은하게 반짝이는 금별 `heatFull`). 주 수는 위젯 폭에 맞춘다(최대 53주)
  - **시계**: 사이드바에도 있어서 기본 구성에는 넣지 않는다
- 기본 구성: 오늘(할 일 6 + 그 아래 다음 할 일 6 · 타임라인 6) / 앞으로(7일 12) / 이번 달(월 달력 8 · 목표 4 + 기록 4). 챙길 것·인박스·시계는 기본에서 빼고 추가 목록에 둔다
- 위젯은 각자 카드(머리글 + 본문)로 구분. 한 줄짜리 정보도 전체 폭을 차지하지 않는다

### 사이드바 (항상)
- 날씨(Open-Meteo, 설정에서 지역), 시계(디지털: 검은 바탕 숫자 / 아날로그: 검은 원판·숫자 없는 흰 바늘 — 눌러서 전환), 날짜, 하루 호, 탭, Claude, 설정

### (이전 안) 대시보드 요약 항목
1. 지금 / 다음 (큰 카드)
2. 한 줄 요약: 오늘 완료 n/m · 남은 할 일 n · 빈 시간 · (밀린 n · 마감 임박 n: 있을 때만, 누르면 오늘 탭)
3. 오늘 남은 일정 3개 (시간순) + "오늘 전체 보기"
4. 이번 주 7일 띠 (누르면 그날의 오늘 탭)
5. 목표 달성률 2개 (월·연) + 인박스 n

### 오늘 (날짜 이동 가능한 일간 보기)
- 상단: ◀ 날짜 ▶ [오늘], 헤드라인 입력
- 왼쪽: (오늘이면) 밀린 할 일 → 전체 목록(완료 항목도 제자리에 취소선, "완료 숨기기" 토글) → 이 날짜로 추가
- 오른쪽: 24시간 타임라인 (드래그 이동·길이 조절, 목록에서 끌어 놓으면 시간 할당)
- 하단: 메모

### 캘린더
- 월: 큰 달력. 칸마다 헤드라인 + 항목 3개 + "n개 더". 항목을 다른 날로 끌어 옮김. 날짜 누르면 오늘 탭. 칸에 마우스를 올리면 + 버튼으로 그날 추가
- 주: 월~일 7열. 열마다 헤드라인과 항목 전체. 열 사이 드래그
- 오른쪽: 이번 달 마감 남은 할 일

### 목표
- 월 목표: ◀ 월 ▶, 달성률, 목록(체크·편집·삭제), 추가
- 연 목표: ◀ 연 ▶, 달성률, 목록, 추가
- 연간 기록: 12개월 카드(월 목표 달성률, 완료 수, 일별 완료 히트맵). 누르면 그 달 캘린더

### 인박스
- 날짜 없는 할 일 전체, 추가. 편집 패널에서 날짜를 정하면 그날로 이동

## 4. 공통 조작 원칙
- 모든 수정은 즉시 파일에 반영하고, 하단에 결과와 **되돌리기**를 6초간 보여준다.
- 삭제는 확인 창 없이 바로 하고 되돌리기로 복구한다.
- 완료한 항목은 목록에서 사라지지 않고 제자리에 취소선으로 남는다.
- 항목 클릭 = 편집 패널, 체크박스 = 완료, 끌기 = 날짜·시간 이동.
