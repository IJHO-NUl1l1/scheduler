# 오늘 할 일 설계: 목록 · 타임라인 · 알림

## 1. 구조: 목록 하나, 보기 둘

```
오늘의 모든 항목 (Daily/오늘.md의 ## 할 일 + 오늘 마감·예정 + 밀린 것)
 │
 ├─ 전체 목록   ← 모든 항목. 시간 있는 것도 포함. 원본에 가까운 보기
 │
 └─ 타임라인    ← 시간이 있는 항목만 뽑아서 시간선 위에 배치
```

- "시간 없는 목록"은 따로 만들지 않는다. 전체 목록에서 시간 있는 항목에 시간 배지가 붙을 뿐이다.
- 시간 할당 = 줄 앞에 `HH:mm-HH:mm`을 붙이는 것. 지우면 타임라인에서 빠지고 목록에는 남는다.
- 하위 항목은 각자 시간을 가질 수 있다. 타임라인에는 `부모 › 하위` 형태로 표시.
- 일정(체크박스 없음, 회의 등)도 같은 목록에 있고 타임라인에 함께 그린다.

## 2. 현재 시간과 대조한 상태

시간 있는 항목마다 현재 시각 기준으로 상태를 계산한다. 파일에는 저장하지 않는다.

| 상태 | 조건 | 표시 |
|---|---|---|
| 예정 | 시작 전 | 기본 |
| 곧 시작 | 시작 10분 전부터 | 강조 + 남은 분 표시 |
| 진행 중 | 시작 ≤ 지금 < 끝 | 가장 강하게 강조, 진행 막대 |
| 지남 · 미완료 | 끝이 지났는데 체크 안 됨 (할 일만) | 경고색, "밀림" 배지 |
| 끝남 | 일정(체크박스 없음)의 끝이 지남 | 흐리게 |
| 완료 | 체크됨 | 흐리게 + 취소선 |

시간 없는 할 일은 상태가 두 가지(미완료/완료)뿐이다. 대신 하루가 끝나갈 때 남은 개수를 알려준다.

### 전체 목록 정렬

1. 진행 중
2. 곧 시작
3. 지남 · 미완료 (밀린 시간 할 일)
4. 시간 없는 미완료: 우선순위 → 마감일
5. 예정 (시간순)
6. 완료·끝남 (접어서 아래로)

정렬은 기본값이고, 사용자가 드래그로 바꾼 순서가 있으면 그걸 따른다.

## 3. 알림

| 시점 | 내용 | 버튼 |
|---|---|---|
| 시작 10분 전 | "14:00 회의 10분 전" | 확인 |
| 시작 시각 | "지금: 자료 조사 (16:00-17:00)" | 확인 / 10분 미루기 |
| 끝 시각 (할 일만) | "자료 조사 끝났나요?" | 완료 / 15분 연장 / 다른 시간으로 / 시간 빼기 |
| 하루 마무리 (기본 18:00) | "오늘 남은 할 일 3개" | 내일로 / Inbox / 열기 |
| 아침 첫 실행 | 오늘 요약 (일정 n개, 할 일 n개, 밀린 것 n개) | 열기 |

- 알림은 Windows 시스템 알림(Electron Notification). 앱 창이 열려 있으면 앱 안의 토스트로 대신.
- 창을 닫아도 트레이에 남아 알림을 계속 보낸다. Windows 로그인 시 자동 실행은 설정에서 선택.
- "10분 미루기", "15분 연장"은 파일의 시간을 실제로 바꾼다 (Claude와 다른 기기에도 반영되게).
- 알림을 이미 보냈는지, 일시 무시 상태 같은 기록은 볼트가 아니라 앱 데이터 폴더에 둔다. 볼트에 쓸데없는 변경이 생기지 않게.
- 설정: 미리 알림 분(기본 10), 마무리 시각, 방해 금지 시간대, 알림 종류별 켜기/끄기.

### 구현 위치

- 상태 계산(`timeStatus(item, now)`)과 다음 알림 시각 계산은 `packages/core`의 순수 함수. 테스트하기 쉽고 MCP에서도 쓴다.
- 타이머와 알림 발송은 desktop의 main 프로세스. 파일이 바뀌면(앱, Claude, git pull 무엇이든) 다시 계산해서 타이머를 갱신한다. Claude가 MCP로 넣은 일정도 자동으로 알림 대상이 된다.
- 절전 해제·시계 변경에 대비해 1분마다 한 번 다시 맞춘다.

## 4. 보조 기능

| 기능 | 내용 |
|---|---|
| 빈 시간 표시 | 타임라인의 빈 구간을 보여주고, 시간 없는 할 일을 끌어다 놓으면 시간 할당 |
| 겹침 경고 | 시간이 겹치는 항목은 나란히 그리고 경고 표시 |
| 지금/다음 카드 | "진행 중: 자료 조사 (24분 남음) · 다음: 17:30 퇴근 전 정리" |
| 남은 시간 대비 할 일 | "오늘 남은 근무 3시간 · 시간 없는 할 일 5개" 같은 한 줄 |

## 5. 홈에 넣을지, 상세 페이지에만 둘지

### 추천: 홈에 둘 다 넣되 압축형으로, 편집은 일간 페이지에서

| | 홈 | 일간 페이지 |
|---|---|---|
| 지금/다음 카드 | O (가장 위) | O |
| 전체 목록 | 미완료만, 상위 7개 정도 + "n개 더" | 전부, 완료 포함 |
| 타임라인 | 세로 미니 타임라인. 범위는 근무 시간(예: 08~19시) 기준, 범위 밖 항목이 있으면 자동 확장 | 24시간 전체, 현재 시각으로 자동 스크롤 |
| 체크·미루기 | O | O |
| 시간 할당 드래그, 순서 변경, 하위 항목 편집 | X | O |

### 이유

- 이 앱의 핵심 목표가 "열자마자 오늘이 눈에 들어오는 것"이다. 시간 대조(지금 뭘 해야 하는지)는 오늘 정보 중 가장 급한 것이라 홈에서 빠지면 안 된다.
- 타임라인만 있으면 시간 없는 할 일이 안 보이고, 목록만 있으면 지금 무엇을 할 차례인지가 안 보인다. 둘이 짝이라 둘 다 필요하다.
- 대신 홈은 보기·체크 위주로 압축하고, 편집 작업은 일간 페이지로 보내서 홈이 복잡해지지 않게 한다.
- 창이 좁을 때는 홈의 미니 타임라인을 접고 지금/다음 카드만 남긴다.

홈 배치는 위젯 단위라 나중에 드래그로 바꿀 수 있다(4단계). 처음엔 위 구성을 기본값으로 만들고, 실제로 써보면서 조정한다.
